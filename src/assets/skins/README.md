# Saisonale Skins

Lege deine Skin-PNGs (64x64) in den Ordner der passenden Jahreszeit:

- `winter/`  (Dezember bis Februar)
- `spring/`  (März bis Mai)
- `summer/`  (Juni bis August)
- `autumn/`  (September bis November)

- `gaming/`  (Videospiel-Charaktere, eigene Kategorie "Gaming", unabhängig von der Jahreszeit)

Der Dateiname wird zum Namen im Launcher, zum Beispiel `Weihnachts_Elf.png` zu "Weihnachts Elf".
Classic oder Slim erkennt der Launcher selbst, du kannst es in der Vorschau umstellen.
Danach neu bauen (`npm run build`). Liegt in einem Ordner keine Datei, zeigt der Launcher stattdessen die mitgelieferten Skins.
